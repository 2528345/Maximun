# MAXIMUN VR-ASSISTANT v2.0 🚀

Este directorio contiene la propuesta completa de la **Versión 2.0** de Maximun, diseñada para ser un sistema autónomo con capacidad de aprendizaje, resiliencia de hardware y razonamiento multimodal avanzado.

## 📂 Estructura del Proyecto
- `config/`: Configuraciones centrales y reglas HMR-ACT inmutables.
- `core/`: Motores de razonamiento, feedback y aprendizaje cognitivo.
- `services/`: Servicios modulares (Audio, Visión, Multimodal, RAG, Hardware).
- `scripts/`: Herramientas de despliegue, monitoreo y protección (Circuit Breaker).
- `docs/`: Análisis comparativo y documentación detallada.

## 🛠 Bloques Implementados
1.  **Bloque-01:** Infraestructura Base (Podman, SSD Protection).
2.  **Bloque-02:** Audio (Whisper-CT2 INT8).
3.  **Bloque-03:** Visión (Qwen2-VL-2B).
4.  **Bloque-04:** Multimodal (MiniCPM-V-2.0).
5.  **Bloque-05:** RAG + Auto-Aprendizaje Reforzado.
6.  **Bloque-06:** Hardware Interface.
7.  **Bloque-07:** Cloud Immortality.
8.  **Bloque-08:** Self-Preservation.
9.  **Bloque-09:** Integración Total.

## 🚀 Despliegue
Para iniciar el sistema:
```bash
podman-compose up -d
```
